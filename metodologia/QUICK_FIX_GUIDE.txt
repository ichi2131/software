TROUBLESHOOTING:
================================================================================

❌ "Puerto 8000 ya está en uso"
   → Cambia el puerto en server.py (línea 11)
   → O cierra la aplicación que usa ese puerto

❌ "Python no se encuentra"
   → Instala Python desde: https://www.python.org
   → Asegúrate de marcar "Add Python to PATH"

❌ "Los gráficos no se generan"
   → Intenta ejecutar manualmente:
     python inventory_charts.py
   → Verifica que exista inventory.json

❌ "Acceso denegado en archivos .bat"
   → Descarga los archivos nuevamente
   → O ejecuta desde CMD/PowerShell directamente
