🛠️ ENDPOINTS DE LA API
═══════════════════════════════════════════════════════════════════════════════

Autenticación:
  POST   /api/login                 - Iniciar sesión
  POST   /api/logout                - Cerrar sesión
  POST   /api/signup                - Registro
  GET    /api/current-user          - Usuario actual

Usuarios (Admin):
  GET    /api/users                 - Listar usuarios
  PUT    /api/users/<id>            - Actualizar
  DELETE /api/users/<id>            - Eliminar
  POST   /api/reset-users           - Resetear

Productos:
  GET    /api/products              - Listar
  POST   /api/products              - Crear
  PUT    /api/products/<id>         - Actualizar
  DELETE /api/products/<id>         - Eliminar
  POST   /api/reset-products        - Resetear

Carrito:
  GET    /api/cart                  - Ver
  POST   /api/cart                  - Agregar
  DELETE /api/cart/<id>             - Eliminar
  POST   /api/cart/clear            - Limpiar

Auditoría:
  GET    /api/activity-log          - Ver logs

Estado:
  GET    /api/health                - Verificar API
