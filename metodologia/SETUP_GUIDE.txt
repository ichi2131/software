🛠️ FUNCIONALIDADES POR ENDPOINT:
═══════════════════════════════════════════════════════════════════════════

Autenticación:
  POST   /api/login          - Iniciar sesión
  POST   /api/logout         - Cerrar sesión
  POST   /api/signup         - Registro
  GET    /api/current-user   - Usuario actual

Usuarios (Admin):
  GET    /api/users          - Listar
  PUT    /api/users/<id>     - Actualizar
  DELETE /api/users/<id>     - Eliminar
  POST   /api/reset-users    - Resetear

Productos:
  GET    /api/products       - Listar
  POST   /api/products       - Crear
  PUT    /api/products/<id>  - Actualizar
  DELETE /api/products/<id>  - Eliminar
  POST   /api/reset-products - Resetear

Carrito:
  GET    /api/cart           - Ver
  POST   /api/cart           - Agregar
  DELETE /api/cart/<id>      - Eliminar
  POST   /api/cart/clear     - Limpiar

Auditoría:
  GET    /api/activity-log   - Ver logs

Salud:
  GET    /api/health         - Estado API

  1. Edita api.py, línea final:
     app.run(debug=True, host='localhost', port=5000)
  2. Actualiza api-client.js:
     const API_BASE_URL = 'http://localhost:NUEVO_PUERTO/api'

Para cambiar base de datos:
  1. Edita database.py:
     DATABASE_FILE = Path(__file__).parent / 'mi_bd.db'

❓ PREGUNTAS FRECUENTES:
═══════════════════════════════════════════════════════════════════════════

P: ¿Qué pasa con mis datos viejos de localStorage?
R: Se crearán nuevos. Los viejos seguirán en el navegador pero no se usarán.

P: ¿Puedo migrar los datos antiguos?
R: Sí, puedes escribir un script Python para importarlos a la BD.

P: ¿Es seguro para producción?
R: Casi. Agrega HTTPS, JWT, y valida todos los inputs en el servidor.

P: ¿Cuántos usuarios puede soportar?
R: SQLite soporta hasta ~5 usuarios simultáneos. Para más, usa PostgreSQL.

P: ¿Cómo hago backup?
R: Copia el archivo inventory.db a otro lugar.
