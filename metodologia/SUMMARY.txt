📊 PROBLEMA 2: GRÁFICOS AUTOMÁTICOS
───────────────────────────────────────────────────────────────────────────────
Se crearon 5 nuevos archivos para automatizar la ejecución:

1. server.py (PRINCIPAL) ⭐
   • Servidor HTTP que sirve los archivos
   • Ejecuta automáticamente inventory_charts.py al iniciar
   • Acepta requests POST en /run_charts para generar gráficos bajo demanda
   • Puerto: 8000 (configurable)

2. startup.py
   • Script simple de inicialización
   • Ejecuta el generador de gráficos y muestra instrucciones
   • Alternativa más ligera a server.py

3. start_server.bat ⭐ RECOMENDADO PARA WINDOWS
   • Script batch para iniciar fácilmente
   • Verifica que Python esté instalado
   • Lanza server.py automáticamente
   • Doble click para ejecutar

4. start_server.ps1
   • Script PowerShell con interfaz mejorada
   • Colores y información formateada
   • Para usuarios de PowerShell en Windows

5. auto_run_charts.bat
   • Ejecuta directamente inventory_charts.py
   • Para generar gráficos sin iniciar el servidor

MODIFICACIÓN EN index.html:
  • Nueva función executeInventoryCharts() que intenta ejecutar el servidor
  • Interfaz visual mejorada mostrando estado de generación
  • Manejo de errores con mensajes al usuario

RESULTADO: ✅ Los gráficos se generan automáticamente al iniciar el servidor

   → Ejecuta: python inventory_charts.py
   → Genera los archivos HTML y JSON
